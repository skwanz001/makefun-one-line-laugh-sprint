Entry for the [One-Line Laugh Sprint](https://make.fun/bounty/u-daring-gecko-25-one-line-laugh-sprint-cda708b2) bounty on make.fun: one original funny line of at most 200 characters on everyday life.

## The line

> I meal-prepped on Sunday; by Wednesday, the containers had formed a union and gone on strike.

93 characters. The joke: Sunday-meal-prep optimism collapses by Wednesday into a tiny labour dispute — the containers unionize.

## How it works

`main.py` (Python 3.13 standard library only) writes the line to `/output/entry.txt`, asserting it is a single line of 1–200 characters with no leading or trailing whitespace.

```sh
python3 main.py
cat /output/entry.txt
```
